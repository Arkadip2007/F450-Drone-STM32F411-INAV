# INAV Drone Documentation Directory

This directory contains complete documentation, master specifications, wiring tables, and technical logs for the autonomous F450 quadcopter.

## Documents List

- **`master-specification.md`**: Master engineering document detailing full hardware BOM, pinouts, timer mapping, PID tuning math, and bench diagnostics.
- **`wiring-and-setup-guide-bn.md`**: Complete wiring and flashing guide written in Bengali (বাংলা গাইড) for Bengali-speaking builders.
- **`wiring-guide.md`**: Pin-to-pin wiring reference for I2C sensors, GPS, receiver, and ESCs in English.
- **`firmware-patches-explained.md`**: Deep dive into the 3 critical firmware patches (MPU clone `0x98`, I2C remap, and 96 MHz USB clock stability).
- **`troubleshooting.md`**: Solutions for arming lockouts, compass calibration, and bench testing phenomena.
