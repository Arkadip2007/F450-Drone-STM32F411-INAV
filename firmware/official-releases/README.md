# Upstream Official INAV Releases

This directory references official stock releases for Black Pill F411 targets from the [INAV GitHub repository](https://github.com/iNavFlight/inav/releases):
- `inav_5.1.0_BLACKPILL_PLANE_SD_108.hex`
- `inav_5.1.0_BLACKPILL_QUAD_SD_108.hex`
- `inav_5.1.0_STM32F411CE.hex`
- `inav_6.0.0_BLACKPILLF411.hex`
- `inav_6.1.1_GLORF411_OSD.hex`

*Note: Stock 108MHz builds suffer from USB freeze on Windows when connecting to INAV Configurator. Use the 96MHz custom build instead.*
